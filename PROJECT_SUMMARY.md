# SHIFTCAST AI — summary
Explainable football intelligence: statistical turning-point detection with evidence ids, non-causal impact graphs, heuristic what-if alternatives, and bilingual (EN/TA) stories whose claims are verified in code. Five logical agents with logged handoffs and automatic fallback. Works offline; optional Azure provider. Synthetic data only; not an official Premier League product.
Measured on synthetic held-out seeds: precision 0.53, recall 0.73 (same-author evaluation). 139 logic tests pass; UI not browser-tested by the builder.
